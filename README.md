# SMS Forwarder for Android

یک اپلیکیشن اندروید ساده جهت فوروارد خودکار پیامک از یک شماره خاص به شماره مشخص دیگر، بدون نیاز به باز بودن مداوم برنامه.

## ویژگی‌ها
- ارسال خودکار پیامک دریافت شده از شماره مبدأ مشخص به مقصد
- فعالیت در پس‌زمینه با استفاده از `BroadcastReceiver`
- سازگار با اندروید 14 تا 16 و نسخه‌های جدیدتر
- بهینه‌سازی شده برای گوشی‌های سامسونگ (One UI) و دستگاه‌های دو سیم‌کارته

## ساخت APK با GitHub Actions
پروژه شامل فایل Workflow در مسیر `.github/workflows/android-build.yml` است که با هر Commit روی شاخه `main` به‌صورت خودکار فایل APK خروجی را در تب **Actions** گیت‌هاب برای دانلود آماده می‌کند.
